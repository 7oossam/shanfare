# الشنفرى — المواجهة الأفقية

لعبة بطاقات عربية للمتصفح. ساحة المواجهة تشغل الثلثين اليسار، وشبكة ٣×٣ تشغل الثلث اليمين، واليد تمتد تحت الجزأين بعرض الشاشة. تعرض كل بطاقة وجهيها بالأرقام والأيقونات. البداية ٦ أوراق: سهمان ودرعان وعزم ومناورة، واليد ٣ أوراق. المظهر ورسوم القتال والبطاقات مستمدة من الصور التي اعتمدها المستخدم.

زر البداية يطلب ملء الشاشة وإخفاء شريط المتصفح مباشرة من ضغطة اللاعب. يوجد زر «ملء الشاشة» ظاهر في رأس اللعبة عند استكمال الحفظ، ويتحول إلى «تصغير» عند الدخول. يدعم الطلب الاتجاه الأفقي عند سماح المتصفح؛ الضغط مطلوب لأن المتصفحات تمنع فرض ملء الشاشة عند تحميل الصفحة.

## اللعب

- بطاقة واحدة في الدور، ثم يرد الأعداء مرة واحدة.
- عند الوضع، تتفعّل جميع البطاقات الموجودة في صف البطاقة وعمودها مرة واحدة، بما فيها البطاقة الموضوعة، حتى لو لم يكتمل الخط. الترتيب من اليسار لليمين ثم من الأعلى للأسفل.
- اكتمال الخط يحدد الإزالة فقط، ولا يضيف تفعيلًا ثانيًا: يُفرّغ الصف المكتمل من ٣ أو العمود المكتمل من ٣. بطاقات الخط الناقص تتفعّل وتبقى.
- الدائمة تبقى حتى إزالة خطها. الطارئة تتفعّل مع الصف والعمود ثم تختفي حتى لو لم يكتمل خط.
- معاينة الخانة تضيء كل البطاقات التي ستتفعّل وتعرض مجموع الضرر والصد ورد الأعداء.
- العزم الدائم يجمع ٢ زخم؛ الطارئ يحوّل الرصيد إلى درع ويصرفه. الصد يحمي من الرد الحالي فقط.
- المناورة الدائمة تعيد دائمة أخرى لليد بعد التفعيل؛ الطارئة تنقل دائمة لخانة فارغة لا تكمل خطًا. الاختيار أو التخطي لا يستهلك دورًا إضافيًا، ويحفظ حتى لو أُغلقت الصفحة.
- تظهر إصابات الأعداء كأرقام متحركة. رد الأعداء يعرض مجموع الضرر الممنوع بالأزرق وخسارة الصحة بالأحمر، مع ملخص مستقل للضرر والدرع المكتسب والمنع وخسارة الصحة. الحركة مخففة عند تفضيل تقليل الحركة.
- بطاقات البداية ممنوعة من الجوائز، بما فيها العروض المحفوظة القديمة. الوابل في الوجهين يضيف كل الزخم إلى ضرره لكل عدو متاح، ويصرف الرصيد مرة واحدة لكل تفعيل.
- الجوائز تتضمن الوابل والنزيف والاغتنام وسهم الصقر والنهش والحصن؛ لم تعد الثبات ضمن الجوائز الجديدة. تعريفاتها القديمة محفوظة لدعم الحفظ السابق.
- لا يوجد نظام خطوات أو حركة.

## التشغيل والتحقق

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
python -m http.server 8765 --directory dist
```

في طرفية أخرى، مع Playwright وChromium:

```sh
node scripts/test_battlefield.cjs
node scripts/test_landscape_campaign.cjs
node scripts/test_fullscreen.cjs
node scripts/test_emergency_lines.cjs
node scripts/test_cross_activation.cjs
node scripts/test_combat_juice.cjs
node scripts/test_nine_grid.cjs
```

يفحص الاختبار البصري تسعة مقاسات أفقية من ٦٦٧×٣٢٠ إلى ١٤٤٠×٩٠٠، ويكتب صور البداية والمعاينة وما بعد التفعيل في `/tmp/landscape-review`. يتحقق من امتداد اليد، ونسبة الساحة، ووضوح وجهي كل بطاقة، واللمس، والحفظ، والتفعيل التلقائي، والزعيم، وتدوير الشاشة. يلعب اختبار الحملة لقاءات كاملة عبر واجهة المتصفح.

## الملفات

- `dist/engine.mjs`: قواعد ٣×٣، الأهداف، الرزمة، الزخم والمواجهات.
- `dist/view.mjs` و`dist/battlefield.css`: الواجهة الأفقية، قصاصات الأصول المعتمدة، الأرقام والأيقونات.
- `dist/combat-feedback.mjs`: تسلسل التأثيرات وأرقام الضرر والصد والمؤثرات المرئية، مبنية على أحداث المحرك الفعلية.
- `dist/app.mjs`: اللمس ولوحة المفاتيح، الحفظ والتفاصيل والحركة المرئية.
- `dist/assets/landscape/`: الصورة الأفقية المرجعية، صورة البطاقات المعتمدة، قالب فارغ لتغطية الأرقام المطبوعة، وشخصية إضافية للمواجهة النهائية.
- الخط Amiri مضمن محليًا بترخيص OFL في `dist/assets/reference/`.

يستمر الحفظ تحت `shanfara-duel-v9`. تُوسّع شبكة الحفظ السابق من ٢×٢ أو ٢×٣ إلى ٣×٣ مع حفظ مواضع البطاقات النسبيّة والصحة والدور والرزمة. تُنقل الأوراق الزائدة في اليد القديمة إلى أعلى الرزمة لتصبح اليد ٣ دون فقد أوراق. الرزمة الجديدة ذات الست متاحة عند بدء جولة جديدة. مجلدات النماذج التاريخية الأخرى لا تدخل في حزمة اللعبة الحالية.
