# الشنفرى — مختبر التوليفات

لعبة بطاقات عربية فردية للمتصفح، بواجهة أفقية وشبكة3×3. لإكمال العمل اقرأ [HANDOVER.md](HANDOVER.md)، وللتصميم اقرأ [قوانين المصمم](docs/design/CARD_DESIGN_RULES.md) و[المرجع الكامل](docs/design/CARD_DESIGN_REFERENCE.txt).

## النموذج الحالي

- تلعب بطاقة واحدة كل دور دون مانا. تختار صفها أو عمودها وخانة فارغة، وتراجع المعاينة ثم تؤكد.
- يتفعّل المختار كله مرة واحدة، حتى لو كان ناقصًا. الصف يمينًا لليسار، والعمود أعلى لأسفل. الخط المكتمل المختار يُفرّغ بعد الحسم دون تفعيل إضافي.
- البطاقات المفرّغة تذهب للمستهلك، ويعاد خلطه عند نفاد السحب. اليد تبدأ3، وتسحب بطاقة بعد الحسم.
-12ورقة:4ضربة محسوبة (ضرر2)،4ساتر (حماية2)،4تقدّم محمي (ضرر1وحماية1، ويصبح الضرر2عند اكتمال المختار). لكل بطاقة تأثير واحد، ولا وجه طارئ.
-3مواجهات تدريب متزايدة الضغط، مع استعادة الصحة24 كاملة بين الاختبارات. النية معلنة، والعدو المقتول لا يرد، والحماية للرد الحالي فقط.
- لا توجد موارد إضافية أو بطاقات أو أعداء من المجموعة السابقة في اللعب الحالي. فكرة عداد التقدم مؤجلة.

هذه نواة اختبار وليست مجموعة مكتملة أو مثبتة التوازن. انظر [الحسابات والفحص الوقائي وحدود المحاكاة](docs/design/PROTOTYPE_BALANCE.md).

## التشغيل والتحقق

```sh
npm install
node --test tests/*.test.mjs
node scripts/build.mjs
python -m http.server 8765 --directory dist
```

وفي طرفية أخرى، مع Playwright وChromium:

```sh
node scripts/test_combo_lab.cjs
```

الاختبار يتحقق من المقاسات الأفقية والمعاينة والتأكيد والحفظ والترحيل وحملة كاملة، ويكتب صورًا في `/tmp/combo-lab-review/`.

يبقى مفتاح الحفظ `shanfara-duel-v9` والقواعد32. يُحتفظ بنسخة احتياطية للحفظ القديم، ثم تبدأ تجربة جديدة بإشعار لأن المحتوى والقواعد تغيرا. الاختبارات والميكانيك السابق مؤرشفان ولا يحددان سلوك النسخة الحالية.

المصدر في `dist/`؛ `dist/app.bundle.js` ملف مولّد باستخدام `scripts/build.mjs`. يستمر التصميم الصحراوي والأصول والخط المحلي. النشر عبر GitHub Pages على [رابط اللعبة](https://7oossam.github.io/shanfare/?v=v32-combo-lab).
