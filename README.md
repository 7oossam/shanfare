# الشنفرى — المواجهة الأفقية

لعبة بطاقات عربية للمتصفح. ساحة المواجهة تشغل الثلثين اليسار، وشبكة ٢×٢ تشغل الثلث اليمين، واليد تمتد تحت الجزأين بعرض الشاشة. تعرض كل بطاقة وجهيها بالأرقام والأيقونات. المظهر ورسوم القتال والبطاقات مستمدة من الصور التي اعتمدها المستخدم.

زر البداية يطلب ملء الشاشة وإخفاء شريط المتصفح مباشرة من ضغطة اللاعب. يوجد زر «ملء الشاشة» ظاهر في رأس اللعبة عند استكمال الحفظ، ويتحول إلى «تصغير» عند الدخول. يدعم الطلب الاتجاه الأفقي عند سماح المتصفح؛ الضغط مطلوب لأن المتصفحات تمنع فرض ملء الشاشة عند تحميل الصفحة.

## اللعب

- اختر عدوًا، ثم وجه بطاقة، ثم خانة فارغة.
- اكتمال صف أو عمود يفعّل بطاقاته تلقائيًا ثم يزيلها. تُقرأ الصفوف من اليسار لليمين والأعمدة من الأعلى للأسفل.
- عند اكتمال خطين معًا، تعمل كل بطاقة مرة واحدة بترتيب الخانات.
- الدائم يعود إلى الرزمة. الطارئ الأقوى يُستنفد حتى المواجهة التالية؛ الضغط على ⓘ أو الضغط المطوّل على وجه البطاقة يشرح ذلك.
- العزم يجمع الزخم. السهم الدائم يصرفه كله كضرر إضافي، والطارئ يصيب بضرر ثابت ويحفظه. الزخم غير المصروف يبقى بين الأدوار ويُصفّر عند اللقاء الجديد.
- الأعداء يهاجمون بعد تفعيل خط. الفوز بهزيمة جميع الخصوم. بعد كل لقاء تختار بطاقة وتستعيد حتى ٦ صحة؛ في الرابع تواجه الزعيم وحاملي التراس.
- لم يعد هناك نظام حركة أو تقدّم أو فوز بالعبور، ولا بطاقات حركة.

## التشغيل والتحقق

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
python -m http.server 8765 --directory dist
```

في طرفية أخرى، مع Playwright وChromium:

```sh
node scripts/test_battlefield.cjs
node scripts/test_landscape_campaign.cjs
node scripts/test_fullscreen.cjs
```

يفحص الاختبار البصري تسعة مقاسات أفقية من ٦٦٧×٣٢٠ إلى ١٤٤٠×٩٠٠، ويكتب صور البداية والمعاينة وما بعد التفعيل في `/tmp/landscape-review`. يتحقق من امتداد اليد، ونسبة الساحة، ووضوح وجهي كل بطاقة، واللمس، والحفظ، والتفعيل التلقائي، والزعيم، وتدوير الشاشة. يلعب اختبار الحملة لقاءات كاملة عبر واجهة المتصفح.

## الملفات

- `dist/engine.mjs`: قواعد ٢×٢، الأهداف، الرزمة، الزخم والمواجهات.
- `dist/view.mjs` و`dist/battlefield.css`: الواجهة الأفقية، قصاصات الأصول المعتمدة، الأرقام والأيقونات.
- `dist/app.mjs`: اللمس ولوحة المفاتيح، الحفظ والتفاصيل والحركة المرئية.
- `dist/assets/landscape/`: الصورة الأفقية المرجعية، صورة البطاقات المعتمدة، قالب فارغ لتغطية الأرقام المطبوعة، وشخصية إضافية للمواجهة النهائية.
- الخط Amiri مضمن محليًا بترخيص OFL في `dist/assets/reference/`.

الحفظ الجديد مستقل تحت `shanfara-duel-v9` لأن قواعد الرقعة والرزمة تغيّرت. الحفظ القديم يبقى على الجهاز دون استخدامه في هذه النسخة. مجلدات النماذج التاريخية الأخرى لا تدخل في حزمة اللعبة الحالية.
