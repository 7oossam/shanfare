# الشنفرى — مختبر التوليفات

لعبة بطاقات عربية فردية للمتصفح، بواجهة أفقية وشبكة3×3. لإكمال العمل اقرأ [HANDOVER.md](HANDOVER.md)، وللتصميم اقرأ [قوانين المصمم](docs/design/CARD_DESIGN_RULES.md) و[المرجع الكامل](docs/design/CARD_DESIGN_REFERENCE.txt).

## النموذج الحالي

- تلعب بطاقة واحدة كل دور دون مانا. تختار صفها أو عمودها وخانة فارغة، وتراجع المعاينة ثم تؤكد.
- يتفعّل المختار كله مرة واحدة، حتى لو كان ناقصًا. الصف يمينًا لليسار، والعمود أعلى لأسفل. الخط المكتمل المختار يُفرّغ بعد الحسم دون تفعيل إضافي.
- البطاقات المفرّغة تذهب للمستهلك، ويعاد خلطه عند نفاد السحب. اليد تبدأ3، وتسحب بطاقة بعد الحسم.
- 17 ورقة من 14 نوعًا: ضربة محسوبة، ساتر، تقدّم محمي (نسختان لكل)، ضربة العارض، استطلاع الأثر، عياذ الصخر، تحصين المرقبة، إشعال النار، إضعاف البأس، ارتطام الترس، **غارة خاطفة، سور الممر، اقتحام، عاصفة الرمل** (⚔️2 «شامل» لكل الأعداء ⏳). بطاقات «⏳ تزول» (الإشعال والتحصين والثلاث الجديدة) تُفعَّل مع الخط ثم تغادر ولا تُكمله. التفاصيل في [HANDOVER.md](HANDOVER.md).
- 5 مواجهات، كل واحدة تعلّم قرارًا، بأعداء من واحد إلى ثلاثة ونوايا دورية معلنة (الصفر = يستعد). تُستعاد الصحة 24 بين المواجهات. العدو المقتول لا يرد، والحماية للرد الحالي فقط، والإضعاف يخص العدو المستهدف وحده. انظر [docs/design/ENCOUNTERS_V35.md](docs/design/ENCOUNTERS_V35.md).
- لا توجد موارد إضافية أو بطاقات أو أعداء من المجموعة السابقة في اللعب الحالي. فكرة عداد التقدم مؤجلة.

هذه نواة اختبار وليست مجموعة مكتملة أو مثبتة التوازن. انظر [الحسابات والفحص الوقائي وحدود المحاكاة](docs/design/PROTOTYPE_BALANCE.md).

## التشغيل والتحقق

```sh
npm install
node --test tests/*.test.mjs
node scripts/build.mjs
python -m http.server 8765 --directory dist
```

وفي طرفية أخرى، مع Playwright وChromium:

```sh
node scripts/test_combo_lab.cjs
```

الاختبار يتحقق من المقاسات الأفقية والمعاينة والتأكيد والحفظ والترحيل وحملة كاملة، ويكتب صورًا في `/tmp/combo-lab-review/`.

يبقى مفتاح الحفظ `shanfara-duel-v9` والقواعد35. يُحتفظ بنسخة احتياطية للحفظ القديم، ثم تبدأ تجربة جديدة بإشعار لأن المحتوى والقواعد تغيرا. الاختبارات والميكانيك السابق مؤرشفان ولا يحددان سلوك النسخة الحالية.

المصدر في `dist/`؛ `dist/app.bundle.js` ملف مولّد باستخدام `scripts/build.mjs`. يستمر التصميم الصحراوي والأصول والخط المحلي. النشر عبر GitHub Pages على [رابط اللعبة](https://7oossam.github.io/shanfare/?v=v38-combo-lab).
